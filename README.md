# ProposalForge PRO - Proposal Management System

Premium proposal builder with dark PRO UI.

## Features
- Dark sidebar PRO dashboard
- Client Management (CRUD)
- Services Catalog with pricing
- Proposal Builder with items
- Public shareable proposal link /p/:token
- Secure auth with ADMIN_PASSWORD
- SQLite database (zero config)
- Bootstrap 5 + Bootstrap Icons + Inter font

## Tech Stack
Node.js, Express, better-sqlite3, Bootstrap 5

## Installation
1. npm install
2. copy .env.example .env (Windows) or cp .env.example .env (Mac/Linux)
3. npm start
4. Open http://localhost:3000 - Login: admin123

## Support
Node 18+ required. No external dependencies.
