ProposalForge PRO - Documentation

Version 1.0 - Node.js Proposal Management

1. Installation

npm install
copy .env.example .env
npm start

Open http://localhost:3000 - Default password: admin123

2. Structure

server.js - Entry
src/app.js - Routes & UI (PRO design)
src/database.js - SQLite init
.env.example - Config example

3. Change Password

Edit .env: ADMIN_PASSWORD=your_new_password

4. Features

  • Dashboard
  • Clients CRUD
  • Services CRUD
  • Proposals + Public Link

5. Support

Node 18+ required. SQLite auto-creates.
